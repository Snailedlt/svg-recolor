Self-hosted fonts (Latin subset, WOFF2), served from our own origin so pages load
without a third-party request.

- `Inter-400-800-latin.woff2`: [Inter](https://github.com/rsms/inter), variable 400–800. License: `Inter-OFL.txt` (SIL OFL 1.1).
- `JetBrainsMono-400-500-latin.woff2`: [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono), variable 400–500. License: `JetBrainsMono-OFL.txt` (SIL OFL 1.1).

The URLs carry `?v=1` so browsers cache them for a year. Bump it if a font file changes.
