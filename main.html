    Why SVG Recolor?

    Changing the color of an SVG shouldn't require opening a design tool.

    Six recolor modes

    Tint, colorize, shift the hue, flatten to one color, go grayscale, or fine-tune hue, saturation and lightness.

    Files or links

    Upload, paste or link to an SVG. Named colors, rgb(), hsl() and black icons without a fill are all handled.

    Website, API & CLI

    Use it here, call the HTTP API from your build pipeline, or run the Python script locally.

    Built for AI agents too

    Let your coding agent recolor icons for you. No API key, no sign-up.

    MCP server

    Add it to Claude Code, Cursor or any MCP client. Tools: recolor_svg, list_svg_colors, list_recolor_modes.

    JSON in, JSON out
    
                            
    Send SVG markup as JSON and get the result plus a color mapping back. The OpenAPI spec has stable operation IDs for tool generation.
    
                            
    POST /api/recolor?format=json
{"svg": "<svg …>", "color": "tomato", "mode": "solid"}

    Use it from code
    
                            
    Everything on this page is available over HTTP, with the same modes and options. No key needed.
    
                            
      
                                
    • GET/api/recolor?url=…Recolor a linked SVG. Works as an <img> src.
      • 
                                
    • POST/api/recolorUpload a file, or send the SVG as the request body.
      • 
                                
    • POST/api/recolor/batchMany files in, one ZIP out.
      • 
                                
    • GET/api/palette?url=…List the colors in an SVG.
      • 
                                
    • GET/api/modesAvailable modes and option ranges.
