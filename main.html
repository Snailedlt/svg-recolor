    How to change the colors of an SVG
    
                    
    Recolor icons, logos and illustrations without opening a design tool. Everything happens on this page.
    
                    
      
                        
    1. Add your SVG. Drop a file, paste the code with Ctrl+V, or load it from a link (GitHub file pages work too).
      2. 
                        
    2. Pick a style. Tint, Colorize, Hue or Solid recolor with one color; Grayscale removes it; Original keeps the colors for fine-tuning.
      3. 
                        
    3. Choose a color and fine-tune. Adjust hue, saturation and lightness, and compare before and after side by side.
      4. 
                        
    4. Download or copy. Get the SVG file, or code for React, Vue, Svelte, Flutter, Tailwind and 19 more formats.
      5. 
                    
    
                    
    
                        
    
                            Does it keep gradients and shading?
                            
    Yes. Colorize and Hue keep each color's lightness, so highlights, shadows and gradients survive; gradient stops are recolored one by one. Solid turns everything into exactly one color, which suits single-color icons.
    
                        
    
                        
    
                            Is my SVG uploaded or stored?
                            
    The editor works on the SVG in your browser and sends only its list of colors to the server to compute the new ones. Nothing is stored. When you load a link, the server downloads that SVG for you.
    
                        
    
                        
    
                            Which colors does it find?
                            
    Hex colors, rgb() and hsl() (with transparency), CSS color names and currentColor, in attributes and in style. Elements without a color, which browsers draw black, are recolored too.
    
                        
    
                        
    
                            Is it free? Can I use it in my app or README?
                            
    Yes. It is free and open source (MIT), with no account or API key. The API tab has ready-to-run code for 21 languages and a Markdown snippet that embeds a recolored icon in a README.

    HTTP API
    
                    
    Everything the editor does is available over HTTP with the same modes and options. The API tab above turns your current settings into ready-to-run code for 21 languages and clients, or an AI prompt for any other.
    
                    
      
                        
    • GET/api/recolor?url=…Recolor a linked SVG. Cached, so it works as an <img> src.
      • 
                        
    • POST/api/recolorUpload a file, send JSON, or send the SVG as the body.
      • 
                        
    • GET/api/map-colors?colors=…Recolor just a list of colors, for design tokens or themes.
      • 
                        
    • POST/api/recolor/batchMany files in, one ZIP out.
      • 
                        
    • GET/api/palette?url=…List the colors in an SVG.
      • 
                        
    • GET/api/modesAvailable modes and option ranges.
