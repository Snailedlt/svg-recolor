Why SVG Recolor?

Changing the color of an SVG shouldn't require opening a design tool.

Keeps the shading

Colors are converted to grayscale and re-tinted, so highlights, shadows and contrast survive the recolor.

Instant & live

Pick a color and watch the preview update. Compare against the original on light, dark or transparent backgrounds.

Website, API & CLI

Use it here, call the HTTP API from your build pipeline, or run the Python script locally.

Automate it with the API

Send a POST request with your SVG and a color as hex (#FF0066) or RGB (255,0,102). You get the recolored SVG straight back.

Swagger docs ReDoc 
# Recolor icon.svg to pink
curl -X POST \
  "https://svg-recolor.jorgenkh.no/colorize?color=%23FF0066" \
  -F "icon=@icon.svg;type=image/svg+xml" \
  -o icon-pink.svg
