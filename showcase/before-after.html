Before and after

The old page was a bare form with one recolor style. The new editor fits on one screen and works for people, scripts and AI agents.

  • One screen: settings, preview, code and Download visible together, no scrolling.
  • Clear settings flow: 1 Style, 2 Color, 3 Adjust, with live thumbnails of your SVG in every style.
  • Six modes built on svgray and svgshift, plus hue, saturation and lightness fine-tuning.
  • Code tab with 23 formats: React, Vue, Svelte, Angular, Python, Flutter and more, each with its icon.
  • API tab with runnable requests in 20 languages and clients, from curl to Rust, Java and C#, plus an AI prompt for any other language.
  • Files, paste or links, drop anywhere, recent colors, keyboard shortcuts, shareable settings.
  • Cheap to run: only the palette goes to the server, and the CDN caches the result for everyone.
  • AI agents: an MCP server, llms.txt and JSON requests.
  • Safer: link fetching blocks private addresses, SVG responses are sandboxed, and the svgray eval() bug is fixed.
